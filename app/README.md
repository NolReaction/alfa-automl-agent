# Alfa Lab

Локальная панель команды для изучения данных и просмотра работы AutoML-агента. Работает в браузере на Python 3.12 с зависимостями существующего проекта. Node.js и дополнительные Python-пакеты не нужны.

## Запуск на Windows

Из корня проекта в PowerShell:

```powershell
.\.venv\Scripts\python.exe app/server.py --open
```

Или дважды нажать `app/start-app.bat`. Откроется `http://127.0.0.1:8765/`. Терминал должен оставаться открытым. Для остановки нажмите Ctrl+C.

Если порт занят:

```powershell
.\.venv\Scripts\python.exe app/server.py --port 8766 --open
```

На Linux/macOS: `.venv/bin/python app/server.py --open`.

## Что внутри

- **Данные:** размеры train/test, типы признаков, пропуски, распределение таргета, статистика выбранного столбца и первые 100 строк train. Значения рассчитываются из файлов на вашем компьютере. Строковые ID и класс `NA` сохраняются.
- **Запуски:** реальные отчёты `.agent_runs`, статусы, события, код экспериментов, stdout/stderr и доступный учёт API-токенов. Открытый экран обновляет журнал во время отдельного запуска агента.
- **Результат:** отчёт стартовой модели, локальная метрика и разбиение, проверка формата текущего `submission.csv`, скачивание предсказаний.

Панель читает данные и отчёты. Она не запускает обучение или API, не изменяет CSV и не запрашивает ключ. Для запуска исследования используйте отдельный терминал; панель покажет записанные агентом события. У каждого участника свой локальный экземпляр и свои файлы. Общая облачная рабочая область в эту версию не входит.

## Подготовка данных и запуск исследования

Если данные уже скачаны и модели обучены, повторять команды не нужно.

```powershell
# Скачать публичные задачи (нужен интернет)
.\.venv\Scripts\python.exe prepare_data.py all

# Обучить стартовую модель без API
.\.venv\Scripts\python.exe offline_baseline.py data/regression/task.md
.\.venv\Scripts\python.exe offline_baseline.py data/classification/task.md

# После настройки выданного Qwen в локальном .env: платный запуск агента
.\.venv\Scripts\python.exe solution.py data/regression/task.md
```

Baseline намеренно не перезаписывает существующий `submission.csv` без `--overwrite`. Приложение не добавляет этот флаг автоматически. Ключи не передавайте в браузер и не сохраняйте в Git.

## Свои задачи

По умолчанию приложение находит папки с `task.md` внутри `data/`. В каждой задаче должен быть один набор `train.csv`, `test.csv`, `data_dictionary.csv`, `sample_submission.csv` в одной вложенной папке. В словаре нужны поля `feature`, `role`, `dtype`, один `id` и один `target`. Типы `numeric`, `category`, `binary` поддерживаются; имя таргета берётся из словаря.

Можно указать другую папку с задачами:

```powershell
.\.venv\Scripts\python.exe app/server.py --data-dir "D:\Hackathon\data"
```

Символические ссылки не обслуживаются. Доступ по HTTP ограничен известными данными и отчётами: универсального чтения путей нет. Сервер слушает только `127.0.0.1`, отвергает посторонние Host/Origin и не принимает команды изменения данных.

## Как читать результаты

Метрика baseline относится к его локальной проверке на train. Текущий CSV мог появиться в другом эксперименте. Прохождение проверки CSV и статус `completed` не доказывают улучшение качества. `fallback` означает сохранённый допустимый результат после ошибки или ограничения. Панель не строит историю улучшений, пока агент не записывает сопоставимые метрики экспериментов.

Если API не вернул usage, токены показаны как неизвестные; неполный usage отмечен отдельно. Стоимость в рублях не рассчитывается. Пустой список запусков нормален до первого исследования: запуск `offline_baseline.py` создаёт отчёт baseline, но не `.agent_runs`.

Профиль CSV кешируется по времени изменения и размеру файлов. Обновление журнала не пересчитывает датасет. Предпросмотр ограничен 100 строками; длинные значения и логи сокращаются. Данные больше 512 МБ на один CSV или 512 столбцов не поддерживаются этой версией.

```powershell
.\.venv\Scripts\python.exe dev_check.py
```
