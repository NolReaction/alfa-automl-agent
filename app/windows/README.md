# Windows launcher

`app/AlfaLab.exe` — настоящий Windows x64 GUI-файл запуска. Дважды нажмите его
в существующем проекте. Он открывает небольшое окно управления и лабораторию
в браузере, без консольного окна.

Это средство запуска установленного проекта: рядом должны оставаться `app/`,
код агента и настроенное окружение Python 3.12 в `.venv/`. Python, библиотеки ML
и датасеты не встроены в EXE. Запускатель ничего не скачивает и не устанавливает.
Отсутствующее окружение, tkinter или зависимости показываются отдельным окном
ошибки. Пользовательские переменные `PYTHONPATH`/`PYTHONHOME` не подменяют Python
проекта: интерпретатор запускается с `-I`.

Окно управления можно свернуть. «Завершить работу» закрывает принадлежащий ему
сервер. При активном эксперименте сначала запрашивается подтверждение остановки;
процесс остаётся живым до сохранения истории и освобождения блокировки. Чужой
процесс на порту 8765 не завершается: лаборатория получает другой свободный порт.

## Исходники и воспроизведение сборки

- `launcher.c` — короткий нативный запускатель с Unicode Win32 API.
- `build_launcher.py` — сборка и независимое чтение PE-заголовков/импортов.
- `elf_to_coff.py` — преобразование ограниченного набора AMD64-релокаций GCC.
- `../desktop.py` — окно управления и жизненный цикл локального Python-сервера.

Для пересборки на Linux x64 нужны Python 3.12, GCC и GNU binutils с эмуляцией
`i386pep`. Дополнительные пакеты Python и Windows SDK не нужны:

```bash
python3 app/windows/build_launcher.py
python3 app/windows/build_launcher.py --verify app/AlfaLab.exe
```

Сборка создаёт временные библиотеки импорта для системных DLL Windows.
Промежуточные объектные файлы и фиктивные DLL удаляются; в поставку входит только
`AlfaLab.exe`. Он импортирует `kernel32.dll` и `user32.dll`, не требует CRT или .NET.
Объектная конвертация сохраняет секционные символы и PC-relative addends; обычный
`objcopy` для основного объекта не используется.

Поставленная сборка: GCC 13.3.0 (Ubuntu), GNU binutils 2.42. Временная метка PE
обнулена. Две независимые пересборки дали одинаковые байты.

Проверены PE32+ AMD64, GUI subsystem, таблица из шести ожидаемых системных

Python-тесты жизненного цикла. Нативный запуск Windows и внешний вид Tk-окна
в этой Linux-среде не проверялись.
