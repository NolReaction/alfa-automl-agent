Мурад расширяет набор алгоритмов. Мы выбираем, какие измеренные кандидаты
успевают пройти полноценную проверку и обучение. Лаборатория независимо измеряет,
дают ли изменения пользу на разных данных при одном и том же бюджете.

Для Мурада и нашей v2 точная база —
`184408390c83ef951e5a570cf9d2d6c3e9e72f98` из PR #27.
База кода лаборатории остаётся `a45861d`; её уже назначенное сравнение:
incumbent `a45861d` vs solver freeze `3b69d50bd7338b9180aaf7d4cb9a101a2a3435ee`.
У `1844083` те же Python sources, что у `3b69d50`; отличается только лимит CI.
В текущий benchmark plan новую v2 или XGBoost молча не подставлять.
Пока PR #27 открыт, новые PR Мурада и v2 направляются в его ветку
`work/finalist-selection-v1`, затем перенаправляются в main после приёмки #27.

История, proposer и ускорение Мурада уже реализованы; прежнее
`team_round3/MURAD_HISTORY_SCHEMA.md` новым заданием не является. Ника и Таня
сохраняют свои согласованные зоны; их файлы эти задания не затрагивают.

Все работают в отдельных ветках/worktree, сохраняют source hashes и отрицательные
результаты. Внешние/платные API и аренда для этих заданий не требуются. GPU-опыты
идут отдельной исследовательской серией; конкурсный кандидат Мурада CPU-only.
Тяжёлые ML-прогоны на одном ПК не совмещать. Code/tests, protocol smoke и
измеренное качество — три разных вида результата. Сведение PR, решение о
defaults, ZIP и платформенная отправка остаются у Димы и основного ИИ.
