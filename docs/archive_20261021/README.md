# Исторические документы перед уборкой веток

Точные копии документов из двух старых веток на 21 октября 2026. Это архив прежних заданий и результатов исследований; актуальные задания команды находятся в `docs/team_round3`. Архивные предложения не означают, что соответствующие экспериментальные режимы включены в конкурсном агенте.

`provenance.json` фиксирует исходную ветку, полный commit SHA, исходный путь и SHA-256 каждой копии. Исходные commits дополнительно сохранены в ancestry ветки `archive/2026-10-21` (`31082a347d152585bffcf2d6f88d941f71902a64`). Уникальный старый код сохраняется там без подключения к main.

- `old_team_plan/`: ранние задания команды из закрытого PR #10.
- `strong_tabular_evidence/`: прежние отчёты strong-tabular; сами по себе не дают допуска режима в runtime.

Внутри копий сохранён исходный текст, включая старые относительные ссылки и описания состояния на момент исследования.
