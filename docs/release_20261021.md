## Уборка веток

Все 28 снимаемых tips сохранены в ancestry `archive/2026-10-21`, commit `31082a347d152585bffcf2d6f88d941f71902a64`; архивную ветку не сливать в main. Устаревшие PR #10, #14 и #18 закрыты после проверки этого архива, без обещания интегрировать их уникальный код.

Девять исторических документов из старого плана команды и strong-tabular evidence сохранены точными копиями в [архиве документации](archive_20261021/README.md). Manifest уборки ссылается на эти копии; provenance содержит исходные commits, пути и SHA-256. Это сохраняет результаты исследований без включения старого кода в runtime.

`cleanup_branches.py` по умолчанию делает только dry-run. Manifest содержит точные SHA 30 старых веток; новые refs он не затрагивает. Перед `--execute` нужны checkout main и обычная Git-авторизация пользователя. Скрипт проверяет fetch/push destination, pinned archive, актуальные heads, main ancestry и локальные worktrees. Удаление использует SHA lease; при расхождении план блокируется. Main, Ника, весь `archive/*` и локально открытые ветки защищены. 29 fake-subprocess tests и независимый review прошли; реальные удаления этими тестами не выполнялись.

```powershell
.\.venv\Scripts\python.exe cleanup_branches.py
# После просмотра dry-run; исходное разрешение на уборку дано капитаном:
.\.venv\Scripts\python.exe cleanup_branches.py --execute
```
