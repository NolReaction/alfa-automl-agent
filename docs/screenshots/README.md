# Скриншоты Alfa Lab для README

В этой папке хранятся настоящие снимки Alfa Lab 0.3 на задаче классификации «Сетевые атаки». Они показаны в [корневом README](../../README.md#alfa-lab--приложение-команды).

| Файл | Экран |
| --- | --- |
| [data.png](data.png) | «Данные»: размер таблиц, распределение классов и проверка train/test |
| [runs.png](runs.png) | «Запуски»: завершённый baseline, локальная метрика и журнал |
| [results.png](results.png) | «Результат»: таблица экспериментов, проверка CSV и выгрузка |

На снимках показан один baseline с Macro F1 около 0.61964 на локальной проверке. Это стартовый результат для сравнения моделей, а не оценка конкурсной платформы.

При обновлении интерфейса заменяйте файлы с теми же именами, чтобы ссылки в README продолжали работать. Снимайте окно браузера при ширине около 1440–1920 пикселей и масштабе 100%. Показывайте настоящие результаты и проверяйте, что в кадре нет ключей и личных уведомлений.

Пути в README относительные: изображения будут доступны и в ветке приложения, и после слияния в `main`. Добавляйте снимки и изменения README в один Pull Request.
