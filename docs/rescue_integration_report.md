# Ранний допуск кандидатов: проверка порядка поиска

База: `d05572846369f3b1e9cfa33f4008dda028db4fe0`, main на 22 октября 2026.

## Изменение

В длинном adaptive-маршруте extensions теперь выполняются после измеренного
baseline и перед очередью обычных локальных рецептов. Раньше до этого hook
нужно было закончить весь warmup; один дорогой fit мог оставить все расширения
без времени. Временная регрессия сначала проверяет историю, затем LightGBM
и CatBoost. В остальных задачах первыми проверяются два бустинга.

Фабрики, численные параметры, INNER-разбиение, caps 64 ordinary + 6 custom,
исходный дедлайн и правила принятия/финализации сохранены. После расширений
обычный поиск продолжает прежнюю очередь в оставшееся время. Ранний запуск
может изменить доступного finalist и расход времени, поэтому native сравнение
измеряет итог системы с новым порядком; одинаковые recipe hashes всех fits
между arms не предполагаются. Ранний ensemble может штатно пропуститься.

Прямые low-level вызовы сохраняют старый порядок по умолчанию:
`extensions_first=False`, `prioritize=False`. Native v3 явно включает новую политику.

## Доказательства

`run.json.local_research` сохраняет `extension_schedule`, факт вызова hook
и остаток времени до/после него. `research_extensions.schedule/order` показывает
фактический порядок, а отдельные trials — frozen hashes, попытку и host feedback.
Вызов hook не равнозначен обучению, победе на outer или публикации.

Статический summarizer не запускает solver, не расходует API и не редактирует
входные отчёты:

```powershell
.\.venv\Scripts\python.exe experiment_rescue_integration_report.py --reports C:\ar\run.json --output C:\ar\summary.json
```

Отсутствующие счётчики/время остаются null. Сводка не заменяет проверку receipts,
пересчёт метрики из CSV и аудит дочерних процессов. Ресурсная квалификация
не выводится из одного успешного native отчёта.

## Сравнение

Парные прогоны на обеих публичных задачах выполняются последовательно,
без API, с фиксированным бюджетом 900 секунд на arm. Классификация использует
один manifest `score_meter`: grouped fit 70155, внешний holdout 17515,
group overlap 0. Регрессия также требует native полного TRAIN, поскольку
derived-task с меньшим числом периодов меняет условия history discovery.

Окружение локальной проверки: Python 3.12, pinned core/CB/LGB из requirements,
квота 8 CPU и 8 GiB RAM. AutoGluon не установлен. Это не полная квалификация
официального окружения с 32 GB и AutoGluon и не оценка скрытого теста.

Результаты измерений будут внесены после завершения arms. До этого выигрыш
качества или допустимость включения политики в конкурсный main не заявляется.
